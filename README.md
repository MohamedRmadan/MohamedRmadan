## 🚀 Things I build

| Project | Tech & what it does |
|---|---|
| **🤖 AI Document Extractor** | `Python` `Odoo` `OWL` `LLM APIs`: reads scanned certificates and PDFs with an LLM into a fixed JSON schema, reconciles the extracted lines, and creates records through a custom OWL review screen. The provider layer is pluggable (Anthropic, OpenRouter, local models). |
| **☁️ Odoo Auto-Provisioning** | `Python` `PostgreSQL` `Docker` `Nginx`: when a tenant signs up, it creates their Odoo database automatically, installs the modules for their industry, and sets up their subdomain. |

| **🩺 Clinic Suite** | `Odoo 18` `Python` `Security rules`: patient journey from enquiry to invoice, clinical records that lock once signed, product lot / expiry / vial traceability, and record rules that limit clinical data to practitioners. |

| **📊 Management Dashboards** | `OWL` `Chart.js` `JSON-RPC`: custom client actions with live KPIs, drill-downs and filters on top of the Odoo ORM. |
| **📨 Vendor RFQ Portal** | `Node.js` `Web` `SMTP`: groups vendors by category, takes PO uploads, and emails each RFQ to every vendor in the matching category. |

- **Security:** groups, ACLs, record rules, field-level and view-level gating.
- **OWL & JS:** custom OWL components, client actions, field widgets, view extensions and **Chart.js** dashboards.
- **Views & reports:** form / list / kanban / pivot / graph views, view inheritance with XPath, and QWeb PDF reports in Arabic and English.
- **Integrations:** XML-RPC, JSON-RPC and REST APIs, webhooks, payment gateways, WhatsApp, and government e-services.
- **Data migration:** **Python + pandas + XML-RPC** pipelines that move legacy ERP and spreadsheet data in cleanly and repeatably.
- **Localization:** Arabic RTL, VAT, **ZATCA Phase 2 e-invoicing**.
- **DevOps:** Odoo.sh branches and staging, Dockerized self-hosted deployments, Nginx reverse proxy, backups, and server sizing for 500+ concurrent users.
- **Upgrades:** porting modules across Odoo 17 → 18 → 19.
